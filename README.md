# 像素沙盒生存游戏 (Terraria风格)

一个2D侧视沙盒生存游戏，玩法和画面效果贴近泰拉瑞亚。

## 运行方式

直接用浏览器打开 `index.html` 即可，无需安装任何环境或构建工具。

推荐使用 Chrome / Edge / Firefox 浏览器。

## 操作说明

| 按键 | 功能 |
|------|------|
| WASD / 方向键 | 移动 |
| 空格 | 跳跃 |
| 鼠标左键 | 挖掘方块 / 攻击 |
| 鼠标右键 | 放置方块 |
| E | 打开/关闭背包与制作菜单 |
| 数字键 1-9 | 选择快捷栏物品 |
| 鼠标滚轮 | 切换选中物品 |

## 游戏玩法

1. **砍树获取木头** - 挖掘树干获得木头
2. **制作工作台** - 按 E 打开制作菜单，用木板合成工作台
3. **合成工具** - 靠近工作台合成镐子、斧头、剑
4. **挖矿** - 用镐子挖掘石头和矿石（铜/铁/金/钻石）
5. **建造房屋** - 放置方块建造封闭空间，放门和火把
6. **生存** - 夜晚僵尸出没，用武器战斗，白天僵尸会燃烧

## 技术栈

- HTML5 Canvas + 原生 JavaScript (ES6+)
- 纯前端单页应用，无后端，无构建工具
- 程序化生成像素贴图，无需外部图片资源
